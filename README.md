# Календарь событий (Java Swing)

Красивое настольное приложение на Java Swing для ведения списка событий.

## Что умеет
- ➕ Добавлять события с названием и датой.
- ✏️ Редактировать выбранные события.
- 🗑 Удалять события с подтверждением.
- 📅 Автоматически сортировать события по дате.
- 🎨 Показывать события в более удобном и аккуратном интерфейсе.

## Требования
- Java 17+ (для использования `record`).

## Запуск
```bash
javac CalendarApplication.java
java CalendarApplication
```

## Формат даты
Используется формат: `yyyy-MM-dd`.
