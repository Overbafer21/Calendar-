# Calendar-

Небольшое Java Swing-приложение для управления календарными событиями.

## Возможности
- Добавление события (название + дата).
- Редактирование выбранного события.
- Удаление выбранного события.
- Отображение списка событий в главном окне.

## Запуск
```bash
javac CalendarApplication.java
java CalendarApplication
```
